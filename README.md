# Calculadora Científica Web
Una calculadora científica sencilla construida únicamente con HTML, CSS y JavaScript (Vanilla JS). 
La idea principal de este proyecto era replicar el comportamiento lógico de una calculadora física real, donde las operaciones se guardan en memoria y el historial se actualiza en una pantalla secundaria al momento de introducir el siguiente valor.
## Características
- **Pantalla dual:** Historial en la parte superior y el ingreso actual en la principal.
- **Operaciones básicas:** Suma, resta, multiplicación y división.
- **Funciones científicas:** Soporte para trigonometría (sin, cos, tan en grados), raíz cuadrada, potencia al cuadrado y el valor de Pi.
- **Corrección de errores:** Opción de borrar dígito por dígito con el botón de retroceso (⌫) o limpiar todo el estado (C).
- **Cero dependencias:** Funciona en cualquier navegador sin necesidad de servidores locales ni frameworks.
## Cómo ejecutarlo
No se requiere ningún proceso de instalación o compilación. 
1. Clona este repositorio o descarga el archivo `.html`.
2. Haz doble clic en el archivo `Calculadora.html` para abrirlo en tu navegador web de preferencia.
## Tecnologías
- HTML5
- CSS3 (Uso de CSS Grid para la distribución fluida de los botones)
- JavaScript (Lógica de operaciones puramente del lado del cliente)
